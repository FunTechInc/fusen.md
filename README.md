# fusen.md

macOS のスティッキーズに次の2つを足した、自分用の付箋アプリです。

- **Markdown 表示**：`# 見出し`、`**太字**`、`- [ ] チェックボックス`、`` `code` `` などを、書いたそばから Notion と同じような見た目で表示します。記号はカーソルのある行だけに表示されます
- **履歴**：過去の版に戻せます。閉じたメモも復元できます

## 使い方

| 操作 | キー |
|---|---|
| 新規メモ | ⌘N |
| メモを閉じる（削除したメモへ移動） | ⌘W |
| 最近閉じたメモを開く | ⇧⌘T |
| メモの履歴 | ⌘Y |
| このメモの履歴 | ⌥⌘Y |
| 常に手前に表示 | ⌥⌘F |
| 半透明 | ⌥⌘T |
| すべてのデスクトップに表示 | ⌥⌘A |
| Markdown 記号をすべて表示（切り替え） | ⇧⌘M |
| 色 | ⌘1〜⌘6 |

- チェックボックスはクリックで切り替わります。リンクは ⌘クリックで開きます。
- 箇条書きの行で Return を押すと、次の項目が自動で続きます。空の項目で Return を押すと終わります。
- 箇条書きの行で Tab を押すと一段深く、Shift+Tab で一段浅くなります（Notion と同じくタブで字下げします）。

## 見た目（Notion 風）

Notion の標準的な見た目に合わせています。

- 見出しは 4 段階です（`#####` と `######` は `####` と同じ表示）
- 箇条書きは • ◦ ▪、チェックボックスは四角（完了は青）、引用は左の縦線、区切り線は細い線で表示します
- インラインコードは赤い文字と灰色の背景、コードブロックは灰色の背景です
- `#` や `**` などの記号は、カーソルのある行でだけ薄く表示され、ほかの行では隠れます。記号を表示しても隠しても文字の位置が横にずれないように、チェックボックス・引用・箇条書きの幅をそろえています
- すべての記号を常に表示したいときは「メモ > Markdown記号をすべて表示」（⇧⌘M）
- 「fusen.md」メニューの「ログイン時に起動」で、Mac の起動時に自動で開くようにできます。

## 履歴のしくみ

「ファイル > メモの履歴…」（⌘Y）で、メモごとの過去の版を見て戻せます。左上の検索欄に言葉を入れると、その言葉を含む版があるメモと版だけに絞り込めます。

履歴には「変更される直前の内容」が自動で保存されます。

- 文字を消す直前：20 文字以上をまとめて消すとき（すべてを選択して削除、貼り付けで上書き、カット、すべてを置換など）と、少しずつ消した合計が 20 文字に達したとき（Delete の長押しなど）
- 編集中は 2 分ごと
- 作文ツール（Writing Tools）で書き換える直前
- メモを閉じたとき、過去の版に戻す直前、アプリを起動したとき
- ほかのアプリでファイルが書き換えられていたとき（上書きする前に、その内容を保存）

閉じたメモは「削除したメモ」に残るので、あとから復元できます（⇧⌘T で直前に閉じたメモを開けます）。過去の版に戻す操作も、メモの画面で ⌘Z を押せば取り消せます。

古い履歴は自動で間引かれます。直近 7 日間はすべて残ります。それより古い「編集前」「起動時」の版は、30 日までは 1 時間に 1 つ、それ以降は 1 日に 1 つになります。「大きな削除の直前」「閉じたとき」などの版は間引かれず、ずっと残ります。

## Notion 連携

メモを Notion のデータベースに一方向でコピー（ミラー）できます。バックアップとして、また Notion から読むために使います。元になるのはあくまでこの Mac のファイルで、元に戻すときはこのアプリの「メモの履歴」を使います。

### 準備

1. Notion の開発者ポータル（https://www.notion.so/developers ）で「内部コネクション」を作り、インストールアクセストークンをコピーします。会社のワークスペースでは、作成にワークスペースオーナーの権限が必要なことがあります。自分の権限で動く「個人アクセストークン」も使えます（ワークスペースで許可されている場合）。
2. 機能（Capabilities）は「コンテンツの読み取り」「コンテンツの挿入」「コンテンツの更新」を有効にします。
3. メモを置きたいページを Notion で開き、右上の ••• > 接続 から作ったコネクションを追加します（個人アクセストークンの場合は不要）。
4. 「fusen.md > 設定…」（⌘,）にトークンとそのページの URL を入れて「接続」を押します。ページの中に「fusen.md」データベースができ、すべてのメモが送られます。

会社のワークスペースにメモを保存してよいかは、社内の規程に従ってご自身で確認してください。

### 同期のしくみ

- 1 メモが 1 ページになります。プロパティは「名前」（1 行目）、「メモID」、「色」、「状態」（使用中／削除済み）、「更新日時」です。
- 入力が 10 秒止まったら送ります（打ち続けていても 1 分に 1 回は送ります）。内容が変わっていなければ送りません。「ファイル > Notionと今すぐ同期」ですぐに送れます。
- 見出し（H1〜H4。H5・H6 は H4）、箇条書き・番号付きリスト（入れ子を含む）、チェックボックス、引用、コードブロック、区切り線、太字・斜体・取り消し線・インラインコード・リンクは、アプリと同じ形で Notion に表示されます。空行もそのまま残ります（入れ子の途中の空行でも入れ子は続きます）。
- アプリで普通の文字として表示されているものは、Notion でも文字のままです。`$` や `|` のように Notion では特別な意味を持つ記号や、字下げした行・箇条書きの中の行頭の `# ` `- ` `1. ` `---` などは、書いたとおりの文字として送ります。
- Notion の書き方にない記法は、同じ見た目になる書き方に直して送ります：`_斜体_`・`__太字__` は `*斜体*`・`**太字**` に、`~~~` のコードブロックは ```` ``` ```` に。リンク先が `note.md` や `#見出し` のように Notion では開けないリンクは、書いたとおりの文字として送ります（リンクのタイトル `"…"` は送りません）。
- 閉じたメモは「状態: 削除済み」になります。Notion のページは削除しません。復元すると「使用中」に戻ります。
- Notion 側でページを削除した（ゴミ箱に入れた）ときは、そのメモを次に同期するときに新しいページを作ります。閉じたメモのページは作り直しません。親ページの共有が外れたときは、何も忘れずに同期を止めます。
- Notion でメモのページにサブページやデータベースを追加すると、本文を置き換えるとそれが消えてしまうため、そのメモの本文は同期されなくなります（設定画面に表示されます。状態と色は同期されます）。ページの外へ移動してから「今すぐ同期」を押してください。
- 一度に大部分を消したとき（空にした、または 200 文字を超えるメモが 4 割未満になった）は、誤操作に備えて 15 分待ち、そのあとも同じ内容なら反映します。
- オフラインのときや Notion が混んでいるときは、あとで自動的に再送します。トークンが無効になったときは同期を止め、設定画面に表示します。
- 同期は Mac から Notion への一方向です。Notion 側で編集した内容は、そのメモを次に付箋で変更したときに上書きされます。
- Notion で編集した内容を付箋に反映したいときは、その付箋で「メモ > Notion の内容を取り込む…」を選びます。確認のあとで付箋の内容が Notion の内容に置き換わります。置き換える前の内容は「メモの履歴」に「Notionから取り込む直前」として保存され、⌘Z でも元に戻せます。Notion で編集したら、付箋を変更する前に取り込んでください。
- コールアウト・トグル・文字色・画像など Notion にしかない要素は、取り込むと付箋ではタグや記号の文字のまま表示され、次に送るときに Notion 側でも普通の文字になります（取り込む前の確認で知らせます）。ページの一部しか読み込めなかったときは、取り込みを中止します。
- 終了するときは、送れていない変更を最大 5 秒待って送ります。

トークンはこの Mac の Keychain（サービス名 `com.github.funtechinc.fusen-md.notion`）にだけ保存され、設定画面には表示されません。`swift run` の開発用ビルドは別のサービス名（`com.github.funtechinc.fusen-md.debug.notion`）を使うので、開発中のメモが本物のトークンで送られることはありません。アプリをビルドし直すと、初回だけ Keychain へのアクセス許可を求められることがあります（「常に許可」を選んでください）。この確認は付箋が表示されてから出ます。「接続を解除」でトークンを削除します。Notion のページはそのまま残ります。

`notion-sync.json`（下記）をなくしたときは同期が止まり、設定画面にそう表示されます。設定で同じページにもう一度接続すると、ページ内の「fusen.md」データベースと各メモのページ（メモID で探します）をそのまま使い、同じものを二重には作りません。

## データの場所

`~/Library/Application Support/fusen.md/`

```
notes/<id>.md              各メモの現在の本文（普通の Markdown ファイル）
index.json                 色・位置・表示設定・削除日時
history/<id>/<日時>.md     過去の版
notion-sync.json           Notion 連携の状態（データベースとページの ID。トークンは含みません）
```

「ファイル > メモのフォルダをFinderで表示」から開けます。Time Machine を使っていれば、このフォルダもバックアップされます。

- `index.json` から漏れた `notes/*.md` は、次に起動したときに開いているメモとして取り込まれます
- 同じフォルダを使うアプリは同時に1つしか起動できません（2つ目は自動で終了します）
- `swift run` で起動した開発用ビルドは、`fusen.md-Debug` という別のフォルダを使います
- 以前の名前（Markdown Stickies）で使っていたメモ（`Application Support/MarkdownStickies`）は、fusen.md を初めて起動したときに自動で引き継がれます

## ビルド

Xcode 27（Swift 6.4）と macOS 26 以降が必要です。

```bash
./scripts/build-app.sh            # build/fusen.md.app を作る
./scripts/build-app.sh --install  # さらに /Applications にインストール
swift test                        # テスト
```

アイコンを作り直すときは `./scripts/make-icon.sh` を実行します。

## 構成

```
Sources/FusenCore/
  App/        起動・メニュー
  Model/      メモのデータ
  Storage/    保存（NoteStore）と履歴（HistoryStore）
  Markdown/   入力中の Markdown 装飾（どの文字が記号か・行の種類も記録）
  Editor/     テキストビュー（リスト継続・字下げ・チェックボックス）と、記号を隠して描くレイアウト（TextKit 1）
  Sync/       Notion 連携（Markdown の変換・API・Keychain・同期）
  Windows/    付箋ウインドウ・履歴ウインドウ・設定ウインドウ
Sources/Fusen/main.swift             起動するだけの入口
Tests/FusenCoreTests/              履歴・保存・装飾・記号を隠す表示・入力（日本語変換を含む）・Notion 連携のテスト（通信はしません）
```
