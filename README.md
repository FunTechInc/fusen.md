# fusen.md

macOS のスティッキーズに次の2つを足した、自分用の付箋アプリです。

- **Markdown 表示**：`# 見出し`、`**太字**`、`- [ ] チェックボックス`、`` `code` `` などを、書いたそばから Notion と同じような見た目で表示します。記号は編集中も表示されません（Notion と同じく、`## ` と打つと見出しになり、記号は消えます）
- **履歴**：過去の版に戻せます。閉じたメモも復元できます

さらに、タスクを進めるための 2 つの機能があります。

- **信号**：タスクに「待機」「進行中」の状態を付けられます。付箋の右上のボタンで、進行中だけ・待機だけを目立たせて表示できます
- **カード**：プロジェクトごとにタスクをまとめる、色と名前の付いた枠です。ドラッグで並べ替えたり、横に並べたりできます

## 使い方

| 操作 | キー |
|---|---|
| すべての付箋を隠す・表示する（ほかのアプリを使っているときも） | ⌃⌥⌘F（設定で変更可） |
| 新規メモ | ⌘N |
| メモを閉じる（削除したメモへ移動） | ⌘W |
| 最近閉じたメモを開く | ⇧⌘T |
| メモの履歴 | ⌘Y |
| このメモの履歴 | ⌥⌘Y |
| 太字・斜体・取り消し線・コード | ⌘B・⌘I・⇧⌘S・⌘E |
| リンク | ⌘K |
| 区切り線 | `---` と入力（または「書式 > 区切り線を挿入」） |
| タスクを一歩進める（待機 → 進行中 → 完了） | ⌘Return（クリックでも） |
| タスクを待機にする・待機を外す | ⌥⌘Return（⌥クリックでも） |
| 見出し・リスト・チェックボックス・信号・カード・引用・区切り線・コードブロックを選ぶ | `/` と入力して選ぶ |
| 常に手前に表示 | ⌥⌘F |
| 半透明 | ⌥⌘T |
| すべてのデスクトップに表示 | ⌥⌘A |
| Markdown 記号をすべて表示（切り替え） | ⇧⌘M |
| 色 | ⌘1〜⌘6 |

- チェックボックスはクリックで切り替わります。リンクは ⌘クリックで開きます。
- 箇条書きの行で Return を押すと、次の項目が自動で続きます。空の項目で Return を押すと終わります。
- 箇条書きの行で Tab を押すと一段深く、Shift+Tab で一段浅くなります（Notion と同じくタブで字下げします）。
- 「fusen.md」メニューの「ログイン時に起動」で、Mac の起動時に自動で開くようにできます。
- ⌃⌥⌘F は、fusen.md 以外のアプリを使っているときでも効きます。付箋が見えているときはすべて隠し、隠れているか、ほかのウインドウの後ろにあるときは手前に表示します。組み合わせは「fusen.md > 設定… > 一般」で変えたり、使わないようにしたりできます（⌘・⌃・⌥ のどれかを含む組み合わせ。アクセシビリティの許可は不要です）。ほかのアプリと同じ組み合わせにすると、どちらか一方しか反応しないことがあります。

## 信号（タスクの状態）

チェックボックスには、未着手・待機・進行中・完了の 4 つの状態があります。待機と進行中が「信号」で、チェックボックスの代わりに丸い印を表示します。待機はオレンジの一時停止マーク（輪も中の 2 本線もオレンジ）、進行中は薄い輪の上を青い弧が回ります。

| 書き方 | 状態 |
|---|---|
| `- [ ] ` | 未着手 |
| `- [>] ` | 待機（次にやるもの） |
| `- [/] ` | 進行中 |
| `- [x] ` | 完了 |

- **クリック**（⌘Return）は一歩進めます：待機 → 進行中 → 完了。未着手はそのまま完了になり、完了は未着手に戻ります。
- **⌥クリック**（⌥⌘Return）は待機にします。待機のタスクは未着手に戻ります。
- キーは、カーソルのある行と、選んだ行すべてに効きます。右クリックと「書式 > タスクの状態」からは、4 つの状態を直接選べます（タスクでない行はタスクになります）。
- 行頭で `[/]` `[>]` と打っても付けられます（`[]` と同じ）。
- **強調表示**：信号のある付箋には、右上に 2 つのボタンが出ます。輪のボタンは進行中のタスクだけ、一時停止のボタンは待機のタスクだけを明るく残し、付箋のほかの部分を暗くします（カードも一緒に暗くなります）。そのタスクの下に字下げして書いた行（Tab で入れ子にした項目や、その中の項目）も、タスクと一緒に明るく残ります。同じボタンをもう一度押すと元に戻ります（「メモ」メニューにもあります）。どちらを表示しているかは付箋ごとに保存されます。表示が変わるだけで、メモの内容は変わりません。
- 進行中の弧は、付箋が画面に見えている間だけ回ります。「システム設定 > アクセシビリティ > 動作 > 視差効果を減らす」がオンのときは回りません。

## カード

カードは、色と名前の付いた枠です。中には普通の Markdown を書けます。

```markdown
:::card orange プロジェクトA
- [/] 進行中のタスク
- [>] 待機のタスク
:::
```

- 「書式 > カードを挿入」か、`/` と打って「カード」を選ぶと、カーソルの行（文字があればその下）にカードができます。行を選んでから挿入すると、その行がカードの中身になります。
- 名前を打って Return を押すと、中身の 1 行目に移ります。中身の最後の空行で Return を押すと、カードの下に出ます（箇条書きの終わり方と同じ）。カードがメモの最後にあるときは、カードの下をクリックしても行ができます。
- 色は Notion と同じ 10 色（default・gray・brown・orange・yellow・green・blue・purple・pink・red）です。カード右上の ••• か、カードの文字のない部分の右クリックで変えられます。同じメニューに「カードを解除」（名前と中身を残して枠だけ外す）と「カードを削除」があります。名前の先頭で Backspace を押しても解除できます。
- **ドラッグ**：カードは、中身の文字の行以外の部分（名前のタグ、その横、左右と下の余白）をつかんで動かせます。つかめるところでは、ポインタが手の形になります。行と行の間に落とすとその位置に移り、別のカードの左右の端に落とすと、そのカードと横に並びます。落とせる位置は線で示されます。Esc で中止、⌘Z で元に戻せます。
- 横に並んだカードは、ファイルでは `::::columns` と `::::` で囲まれます。付箋の幅が足りないとき（1 枚あたり 110pt 未満）は、表示だけ縦に並びます。ドラッグでも、収まらない枚数は横に並べられません。
- カードを選ぶときは 1 枚まるごとになります（カードの外から中へ、名前から中身へ選択を広げると、カード全体が選ばれます）。カードの中だけ、名前の中だけの選択はそのままです。
- 閉じる行（`:::`）がないと、開始の行は書いたとおりの文字のまま表示されます。カードの中にカードは入れられません。強調表示では、カードも付箋と一緒に暗くなり、中の進行中（待機）のタスクだけが明るく残ります。

## 書き方（Notion と同じ）

行頭で次のように打つと、スペースを打った時点でその形に変わり、記号は見えなくなります（記号は英数入力で打ちます）。この一覧は「fusen.md > 設定… > Markdown」でも見られます。

| 入力 | 結果 |
|---|---|
| `# ` `## ` `### ` `#### ` | 見出し 1〜4 |
| `- ` | 箇条書き |
| `1. ` | 番号付きリスト |
| `[]`（または `- [ ] `） | チェックボックス（`[]` はスペースなしで変わります） |
| `[>]` `[/]`（または `- [>] ` `- [/] `） | 待機・進行中のタスク |
| `/`（行頭かスペースの後。日本語入力では `；`） | ブロックを選ぶメニュー（下の「`/` メニュー」を参照） |
| `> ` | 引用 |
| `---` | 区切り線（カーソルは次の行へ） |

文中の `**太字**`、`*斜体*`、`~~取り消し線~~`、`` `コード` ``、`[リンク](URL)` も、閉じた時点で書式になります。文字を選んで ⌘B などを押すと書式が付き、選んだ文字がすべてその書式なら外れます（太字の一部だけ外すこともできます）。何も選ばずに ⌘B を押すと、次に打つ文字が太字になります（日本語入力でも同じ）。太字の中で押すと、次に打つ文字は太字になりません。

- 見出しや箇条書きの先頭で Backspace を押すと、普通の文章に戻ります。先頭で Return を押すと、見出し・引用は上に空の行が、箇条書き・チェックボックスは上に空の項目ができます（チェックは元の項目に残ります）。太字やリンクの途中で Return を押すと、どちらの行も太字・リンクのまま分かれます。
- カーソルは隠れた記号の中には止まらず、矢印キーは 1 回で見えている文字 1 つ分動きます。Backspace / Delete、⌥⌫ / ⌘⌫、選んだ文字の削除・上書き・貼り付けでも、隠れた記号は壊れません（中身がなくなった太字やリンクは、記号ごと消えます）。太字やリンクの文字を選んで打ち直すと、太字・リンクのまま置き換わります。区切り線は Backspace 1 回で消え、区切り線の上で打った文字や貼り付けた文字は次の行に入ります。
- `\*` のように記号の前に `\` を付けると、その記号は書式にならず文字として表示されます（Markdown のエスケープ）。対象はこのアプリで書式に使う記号（`` \ ` * _ ~ [ ] ( ) # + - . > ! ``）の前の `\` だけで、`\{` や `\d` などはそのまま表示されます。
- 記号を直接編集したいとき（リンク先の URL を直すときなど）は「メモ > Markdown記号をすべて表示」（⇧⌘M）で記号を表示します。

### `/` メニュー

Notion と同じく、`/` と打つと、メモに書けるブロックがすべて並びます：テキスト、見出し 1〜4、箇条書き、番号付きリスト、チェックボックス、待機のタスク、進行中のタスク、カード、引用、区切り線、コードブロック。各行の右端には、メニューを使わずに同じブロックを作る記号（`#` `-` `[]` など）が出ます。

- 続けて打つと絞り込めます。英語（`h2`、`todo`、`quote`、`ca`）、読み（「みだし」「しんこう」）、記号（`##`、`[/`）のどれでも探せます。↑↓ で選び、Return か Tab かクリックで決定、Esc で閉じます。一覧は 9 行分の高さで、選んでいる行に合わせてスクロールします。
- 選ぶと、カーソルのある行がそのブロックになります。行に文字があれば文字は残り、記号だけが入れ替わります（箇条書きの行で「見出し 2」を選ぶと、同じ文字の見出しになります）。字下げは、入れ子にできるブロック（テキスト・リスト・チェックボックス）では残ります。番号付きリストは、上の行の番号の続きになります。
- カード・区切り線・コードブロックは、行が空ならその行に、文字があればその下に入ります。

## 見た目（Notion 風）

Notion は公式のスタイルガイドを公開していないため、Notion の実際の表示と、それを再現したオープンソースの定番スタイル（react-notion-x）の値に合わせ、付箋の大きさ（1em = 14pt）に縮めています。

- 本文は行の高さ 1.5、文字色 rgb(55, 53, 47)
- 見出しは 4 段階（1.875 / 1.5 / 1.25 / 1.15em、太さ 600、行の高さ 1.3）。`#####` と `######` は `####` と同じ表示
- 箇条書き（• ◦ ▪）・番号・チェックボックス（1em 四方、完了は青）は幅 1.5em の列の中央に置き、本文はどれも同じ位置（1.625em）から始まります。入れ子は同じ幅ずつ下がります
- 引用は左の太さ 3pt の線と 1.2em の文字、区切り線は細い線、インラインコードは赤い文字と灰色の背景、コードブロックは灰色の背景（内側に 1em の余白）
- スクロールバーはスティッキーズと同じ小さいサイズです
- 信号は、チェックボックスと同じ大きさ（1em）の輪です。進行中は、区切り線と同じ薄さ（文字色の 16%）の輪の上を弧が回ります。弧はチェック済みのチェックボックスと同じ青（rgb(35, 131, 226)）で、1.2 秒で 1 周します。待機は一時停止マークで、輪も中の 2 本線も Notion のオレンジ（rgb(217, 115, 13)）です。Figma の案（水色の輪とピンクの一時停止マーク）をもとに、アプリのほかの印と色に合わせて整えました
- カードは、カードの色で塗った角の丸い四角です。左上に名前のタグ、右上に •••、その下に中身をそのまま書きます（中身用の白い面はありません）。中身は名前のタグの左端にそろい、カードの端からの余白は 8pt です。オレンジとパープルは Figma の色、ほかの 8 色は Notion の色見本から同じ規則で決めた色です。強調表示は、付箋を 67% の黒で暗くし、対象以外を 31% の濃さにします

## 履歴のしくみ

「ファイル > メモの履歴…」（⌘Y）で、メモごとの過去の版を見て戻せます。左上の検索欄に言葉を入れると、その言葉を含む版があるメモと版だけに絞り込めます。

履歴には「変更される直前の内容」が自動で保存されます。

- 文字を消す直前：20 文字以上をまとめて消すとき（すべてを選択して削除、貼り付けで上書き、カット、すべてを置換など）と、少しずつ消した合計が 20 文字に達したとき（Delete の長押しなど）
- 編集中は 2 分ごと
- 作文ツール（Writing Tools）で書き換える直前
- メモを閉じたとき、過去の版に戻す直前、アプリを起動したとき
- ほかのアプリでファイルが書き換えられていたとき（上書きする前に、その内容を保存）

閉じたメモは「削除したメモ」に残るので、あとから復元できます（⇧⌘T で直前に閉じたメモを開けます）。過去の版に戻す操作も、メモの画面で ⌘Z を押せば取り消せます。

古い履歴は自動で間引かれます。直近 7 日間はすべて残ります。それより古い「編集前」「起動時」の版は、30 日までは 1 時間に 1 つ、それ以降は 1 日に 1 つになります。「大きな削除の直前」「閉じたとき」などの版は間引かれず、ずっと残ります。

## Notion 連携

メモを Notion のデータベースに一方向でコピー（ミラー）できます。バックアップとして、また Notion から読むために使います。元になるのはあくまでこの Mac のファイルで、元に戻すときはこのアプリの「メモの履歴」を使います。

### 準備

1. Notion の開発者ポータル（https://www.notion.so/developers ）で「内部コネクション」を作り、インストールアクセストークンをコピーします。会社のワークスペースでは、作成にワークスペースオーナーの権限が必要なことがあります。自分の権限で動く「個人アクセストークン」も使えます（ワークスペースで許可されている場合）。
2. 機能（Capabilities）は「コンテンツの読み取り」「コンテンツの挿入」「コンテンツの更新」を有効にします。
3. メモを置きたいページを Notion で開き、右上の ••• > 接続 から作ったコネクションを追加します（個人アクセストークンの場合は不要）。
4. 「fusen.md > 設定…」（⌘,）にトークンとそのページの URL を入れて「接続」を押します。ページの中に「fusen.md」データベースができ、すべてのメモが送られます。

会社のワークスペースにメモを保存してよいかは、社内の規程に従ってご自身で確認してください。

### 同期のしくみ

- 1 メモが 1 ページになります。プロパティは「名前」（1 行目）、「メモID」、「色」、「状態」（使用中／削除済み）、「更新日時」です。
- 入力が 10 秒止まったら送ります（打ち続けていても 1 分に 1 回は送ります）。内容が変わっていなければ送りません。「ファイル > Notionと今すぐ同期」ですぐに送れます。
- Notion とのやり取りには、Notion の Markdown（Notion-flavored Markdown。API では `markdown_version: "v2"`）を使います。以前の書式（enhanced markdown、v1）は Notion が廃止を予告しているため、使いません。
- 見出し（H1〜H4。H5・H6 は H4）、箇条書き・番号付きリスト（入れ子を含む）、チェックボックス、引用、コードブロック、区切り線、太字・斜体・取り消し線・インラインコード・リンクは、アプリと同じ形で Notion に表示されます。空行もそのまま残ります（入れ子の途中の空行でも入れ子は続きます）。
- カードは、同じ色のコールアウト（アイコンは 📌）になります。名前はコールアウトの 1 行目に太字で入り、中身はその中のブロックになります。横に並べたカードは段組み（列ごとにコールアウト 1 つ）になります。
- 待機・進行中のタスクは、チェックの付いていない To-do として送り、文字色で区別します（進行中は青、待機はオレンジ）。
- アプリで普通の文字として表示されているものは、Notion でも文字のままです。`$` や `|` のように Notion では特別な意味を持つ記号、`<b>` や `<p />` のような Notion のタグ、`&amp;` のような文字参照、字下げした行・箇条書きの中の行頭の `# ` `- ` `1. ` `> ` `---` などは、書いたとおりの文字として送ります。
- 太字・斜体・取り消し線は、Notion のタグ（`<b>` `<i>` `<s>`）にして送ります。`**太字**` と `__太字__`、`*斜体*` と `_斜体_` は同じ書式です。タグにするのは、`**「強調」**です` のように記号のすぐ隣がかっこや句読点のとき、Markdown の決まりでは太字と読まれないことがあるためです（付箋では太字なので、Notion でも同じ範囲が太字になります）。
- `~~~` のコードブロックは ```` ``` ```` にして送ります。コードの中に ```` ``` ```` があるときは、囲む記号をそれより長くします。リンク先が `note.md` や `#見出し` のように Notion では開けないリンクは、書いたとおりの文字として送ります（リンクのタイトル `"…"` は送りません）。
- 閉じたメモは「状態: 削除済み」になります。Notion のページは削除しません。復元すると「使用中」に戻ります。
- Notion 側でページを削除した（ゴミ箱に入れた）ときは、そのメモを次に同期するときに新しいページを作ります。閉じたメモのページは作り直しません。親ページの共有が外れたときは、何も忘れずに同期を止めます。
- Notion でメモのページにサブページやデータベースを追加すると、本文を置き換えるとそれが消えてしまうため、そのメモの本文は同期されなくなります（設定画面に表示されます。状態と色は同期されます）。ページの外へ移動してから「今すぐ同期」を押してください。
- 一度に大部分を消したとき（空にした、または 200 文字を超えるメモが 4 割未満になった）は、誤操作に備えて 15 分待ち、そのあとも同じ内容なら反映します。
- オフラインのときや Notion が混んでいるときは、あとで自動的に再送します。トークンが無効になったときは同期を止め、設定画面に表示します。
- 同期は Mac から Notion への一方向です。Notion 側で編集した内容は、そのメモを次に付箋で変更したときに上書きされます。
- Notion で編集した内容を付箋に反映したいときは、その付箋で「メモ > Notion の内容を取り込む…」を選びます。確認のあとで付箋の内容が Notion の内容に置き換わります。置き換える前の内容は「メモの履歴」に「Notionから取り込む直前」として保存され、⌘Z でも元に戻せます。Notion で編集したら、付箋を変更する前に取り込んでください。
- 取り込むとき、コールアウトはカードになります（色はカードの色に。1 行目がすべて太字ならカードの名前に、そうでなければ中身の 1 行目になります。アイコンは残りません）。列ごとにコールアウトが 1 つだけ入った段組みは、横に並んだカードになります。それ以外の段組みは中身を縦に並べて取り込みます（取り込む前の確認で知らせます）。青・オレンジの To-do は進行中・待機のタスクになります。
- トグル・表・文字色・画像など Notion にしかない要素は、取り込むと付箋ではタグや記号の文字のまま表示され、次に送るときに Notion 側でも普通の文字になります（取り込む前の確認で知らせます）。色の付いた段落・見出し・箇条書きなどは、ブロックはそのまま取り込み、色を表すタグの 2 行（`<p color="blue">` と `</p>` など）が前後に文字として残ります。表は 1 行ずつ `| a | b |` の形の文字になります。ページの一部しか読み込めなかったときは、取り込みを中止します。
- 入れ子は、付箋ではタブの字下げになります。付箋では入れ子にできないブロック（コードブロック・見出し・引用・区切り線）は、字下げなしで取り込みます。番号付きリストの番号は、Notion の表示と同じく 1 つずつ増える番号になります。コードブロックの言語名は Notion が短い名前で返すため、`python` が `py` になるなど、書いたときと変わることがあります（言語なしのブロックは言語なしのままです）。
- 取り込んだ内容は、Notion と同じ見え方になるように付箋の書き方に直します。Notion で文字として表示されている `*` や `#` などは、付箋でも文字のまま表示されます（必要なところだけ `\` を付けます。`\` は表示されません）。数式は書かれたとおりの文字として表示し、コードとリンク先は書き換えません。取り込んだ内容をそのまま Notion へ送り返すことはありません（取り込みの確認中に付箋の変更が Notion へ送られていた場合は、取り込んだ内容を改めて送ります）。
- 終了するときは、送れていない変更を最大 5 秒待って送ります。

トークンはこの Mac の Keychain（サービス名 `com.github.funtechinc.fusen-md.notion`）にだけ保存され、設定画面には表示されません。`swift run` の開発用ビルドは別のサービス名（`com.github.funtechinc.fusen-md.debug.notion`）を使うので、開発中のメモが本物のトークンで送られることはありません。アプリをビルドし直すと、初回だけ Keychain へのアクセス許可を求められることがあります（「常に許可」を選んでください）。この確認は付箋が表示されてから出ます。「接続を解除」でトークンを削除します。Notion のページはそのまま残ります。

`notion-sync.json`（下記）をなくしたときは同期が止まり、設定画面にそう表示されます。設定で同じページにもう一度接続すると、ページ内の「fusen.md」データベースと各メモのページ（メモID で探します）をそのまま使い、同じものを二重には作りません。

## データの場所

`~/Library/Application Support/fusen.md/`

```
notes/<id>.md              各メモの現在の本文（普通の Markdown ファイル）
index.json                 色・位置・表示設定（強調表示を含む）・削除日時
history/<id>/<日時>.md     過去の版
notion-sync.json           Notion 連携の状態（データベースとページの ID。トークンは含みません）
```

「ファイル > メモのフォルダをFinderで表示」から開けます。Time Machine を使っていれば、このフォルダもバックアップされます。

- `index.json` から漏れた `notes/*.md` は、次に起動したときに開いているメモとして取り込まれます
- 同じフォルダを使うアプリは同時に1つしか起動できません（2つ目は自動で終了します）
- `swift run` で起動した開発用ビルドは、`fusen.md-Debug` という別のフォルダを使います
- 以前の名前（Markdown Stickies）で使っていたメモ（`Application Support/MarkdownStickies`）は、fusen.md を初めて起動したときに自動で引き継がれます

## ビルド

Xcode 27（Swift 6.4）と macOS 26 以降が必要です。

```bash
./scripts/build-app.sh            # build/fusen.md.app を作る
./scripts/build-app.sh --install  # さらに /Applications にインストール
swift test                        # テスト
```

アイコンを作り直すときは `./scripts/make-icon.sh` を実行します。

## 構成

```
Sources/FusenCore/
  App/        起動・メニュー
  Model/      メモのデータ
  Storage/    保存（NoteStore）と履歴（HistoryStore）
  Markdown/   入力中の Markdown 装飾（どの文字が記号か・行の種類も記録）、タスクの状態、カードの記法と並べ替え
  Editor/     テキストビュー（リスト継続・字下げ・チェックボックス・信号・カードのドラッグ・/ メニュー）と、記号を隠して描くレイアウト（TextKit 1）
  Sync/       Notion 連携（Markdown の変換・API・Keychain・同期）
  Windows/    付箋ウインドウ・履歴ウインドウ・設定ウインドウ
Sources/Fusen/main.swift             起動するだけの入口
Tests/FusenCoreTests/              履歴・保存・装飾・記号を隠す表示・入力（日本語変換を含む）・信号・カード・Notion 連携のテスト（通信はしません）
```
